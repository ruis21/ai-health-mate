# AI Health Mate
> 웨어러블 · 스마트폰 데이터를 기반으로  
> **예방 중심 건강 인사이트를 제공하는 AI 헬스케어 웹 플랫폼**

## 🔗 Demo
- Live Site: https://ai-health-mate-site.netlify.app/
- GitHub: https://github.com/yerim-kang/ai-health-mate

---

## 📌 Overview

AI Health Mate는 단순히 심박수·걸음 수를 보여주는 것이 아니라  
**운동 · 수면 · 식단 데이터를 통합 분석하여 예방 중심의 건강 지표를 제안하는 웹 서비스**입니다.

기존 헬스케어 서비스가 ‘기록 중심’에 머무는 것에 착안해,  
사용자에게 **다음 행동을 제안하는 인터페이스**를 설계했습니다.

---

## 🎯 Core Concept

- 데이터 시각화 + 인사이트 제공
- 단순 통계 → 행동 유도형 UI
- 다양한 웨어러블 기기 확장 가능 구조 설계

---

## ✨ Key Features

- 운동 / 수면 / 식단 지표 시각화 UI
- AI 기반 건강 개선 제안 영역 설계
- 완전 반응형 레이아웃 (Desktop / Tablet / Mobile)
- 인포그래픽 기반 건강 점수 표현
